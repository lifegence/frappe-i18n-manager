# 実画面巡回の運用フロー（Frappe Cloud の本番サイト向け、1 枚）

**版**: v1.0 Draft ／ 2026年9月20日 ／ 社外秘 ／ 作成: 板倉 禅（Made in Z）／ 宛先: 野村 正和（ライフジェンス株式会社）

前提: 本番サイト（Frappe Cloud）ではブラウザを動かせないため、巡回は貴社の検証環境から行い、結果もそこに入る。本番の台帳へ自動で届ける仕組みは今回の範囲外。

---

## 登場する場所と人

| 場所 | 役割 | 担当（案） |
|---|---|---|
| 本番サイト（Frappe Cloud） | 巡回される側。巡回用ユーザー（閲覧専用）だけを置く | 貴社のサーバー担当 |
| 検証環境（貴社の version-15 ベンチ） | 巡回マシン。本番と同じアプリを入れ、走査と台帳をここで持つ（翻訳ファイルは揃えなくてよい。判定は本番が配っている訳で行う） | 貴社のサーバー担当 |
| 翻訳台帳・指摘（検証環境の中） | 巡回の結果を読み、訳を入れ、指摘を振り分ける場所 | 翻訳担当・レビュー担当 |
| アプリのリポジトリ（対象アプリ） | 訳の最終的な置き場。ここに CSV を入れて本番へ配る | 開発担当 |

## 流れ

```
①準備 ──▶ ②巡回 ──▶ ③レビュー ──▶ ④書き出し ──▶ ⑤配布 ──▶ ⑥反映検証 ──▶（次回は②へ）
```

| # | 何をする | どこで | 誰が | 出るもの |
|---|---|---|---|---|
| ① 準備 | 本番に巡回用ユーザー（閲覧専用、対象アプリの read 権限、表示言語 ja）を置く。検証環境のアプリ構成を本番と同じにしておく | 本番・検証環境 | サーバー担当 | — |
| ② 巡回 | 検証環境の多言語管理設定に本番の URL と巡回用ユーザーを入れ、走査を実行（画面またはコマンド）。1 回 300〜400 画面で 15〜20 分 | 検証環境 | サーバー担当 | 走査記録（新規・未適用・**未配布**・確認済みの件数、未配布の一覧、回った画面の一覧） |
| ③ レビュー | 台帳を「出所 ＝ 実画面」で絞って新規の未訳を読み、訳す／対象外にする。指摘を「翻訳関数の未適用」で絞り、詳細が `screen:` の行は**訳では直らない**（Frappe 本体かアプリの描画の修正が要る）ので、開発担当へ回す。走査記録の `Not delivered to the site` の一覧は、訳はできているが本番に届いていないものなので、⑤ へ | 検証環境の台帳と指摘 | 翻訳担当 → レビュー担当 | 承認済みの訳、開発担当への修正依頼、配布待ちの一覧 |
| ④ 書き出し | ロケールから「エクスポート → アプリ同梱 CSV」でアプリごとの CSV を出す | 検証環境 | 翻訳担当 | `<app>/translations/ja.csv` |
| ⑤ 配布 | CSV をアプリのリポジトリに入れ、本番へデプロイ | リポジトリ・本番 | 開発担当 | 本番の翻訳ファイル更新 |
| ⑥ 反映検証 | 本番へ配ったあと、もう一度巡回を実行し、走査記録の `not delivered` が 0 になったことを見る（本番が実際に配っている訳で判定するため、これが本番の反映確認になる）。本番でキャッシュが古ければ `bench clear-cache`。検証環境の翻訳ファイルも同じ CSV に更新しておくと、検証環境自身の反映検証（反映済み／未反映／キャッシュ古い／上書き）も揃う | 検証環境から本番へ | サーバー担当 | `not delivered` 0 件の走査記録 |

## 頻度の目安

- 巡回（②〜③）: アプリの改修を本番に配ったあと、または月 1 回
- 反映検証（⑥）: 翻訳ファイルを配るたび

## 注意

- 判定は本番が配っている訳で行うので、検証環境と本番の翻訳ファイルがずれていても結果は狂いません。ずれは `not delivered` の件数として見えます。
- 走査記録に `could not be read from the desk` が出たときだけ、検証環境の辞書で判定しています。このときは検証環境と本番の翻訳ファイルを揃えてから、巡回をやり直してください。
- 巡回は同じロケールで重ねて始められません。定期実行と手動実行が重ならないようにしてください。
- 巡回用ユーザーのパスワードは検証環境の設定に保存され、System Manager なら読み出せます。他で使っていないパスワードにしてください。
- 本番サイトの台帳（もし本番にも本アプリを入れる場合）には巡回の結果は入りません。台帳は検証環境のものを正とします。
