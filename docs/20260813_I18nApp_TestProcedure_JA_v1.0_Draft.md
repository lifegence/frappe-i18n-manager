### C-10 対象アプリの絞り込み

| # | 手順 | 期待結果 | 判定 | 所見 |
|---|---|---|---|---|

| C-12 | C-10 のあとロケールを開く | **指定した対象アプリの行が消えていない**（走査は件数を更新するだけ） | | |

| C-14 | 対象アプリを空にして走査 | `NOT MEASURED` が**出ない**。導入済み全アプリが対象 | | |

## L. 既知の制限

確認時に「不具合ではない」と判断していただきたい点です。

| # | 内容 |
|---|---|
| L-1 | **実画面の自動巡回は未実装です。**実際に描画される文字を拾う機能はありません |
| L-2 | **「英字残り」は件数が多く出ます。**ブランド名・単位・略号を「英字のまま許容する語」に登録して減らす運用が前提です。指摘一覧であってエラー一覧ではありません |
| L-3 | 走査の対象は**サイトに導入済みのアプリ**に限られます |
| L-4 | データベース経路は、あらかじめ定義した DocType とフィールドの一覧を見ます。網羅は完全ではありません |
| L-5 | `/apps/lifegence_i18n` は 404 です。Frappe に `/apps/<アプリ名>` という経路がありません |
| L-6 | 機械翻訳の実行、帳票（APITemplate）の多言語化は範囲外です |
| L-7 | **台帳の訳は「サイトへ反映」を実行するまで画面に出ません。**ロケールごとの操作です |
| L-8 | 本アプリ自身の画面は**英語が原文**です。日本語以外の表示言語では英語で表示されます（未対応言語では原文が出るのが正しい挙動です） |
| L-9 | **走査ログと指摘の本文は英語**で記録されます。診断用データであり、表示時の翻訳は行いません |
